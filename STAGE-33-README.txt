Himo — Stage 33

المرحلة: تجهيز خادم Himo للإنتاج بشكل قابل للتهيئة

تم تنفيذ:
1. إزالة الاعتماد الإجباري على عنوان الاستماع الثابت داخل الكود عند تشغيل الخادم.
2. أصبح Himo.Api يحترم ASPNETCORE_URLS إذا تم ضبطه في بيئة التشغيل.
3. الاحتفاظ بعنوان التطوير المحلي http://0.0.0.0:5080 كقيمة افتراضية فقط عند عدم وجود إعداد خارجي.
4. هذا يسمح لاحقًا بتشغيل الخادم خلف HTTPS/Reverse Proxy أو على منفذ مختلف دون تعديل الكود.
5. لا توجد أسرار أو مفاتيح إنتاجية مضافة إلى المشروع.

الخطوات التالية:
- إغلاق إعدادات الإنتاج المتبقية (HTTPS/domain/SMS/FCM server secret).
- مراجعة Release configuration.
- بعد اكتمال جميع مراحل البناء فقط: اختبار جهازين Android من البداية للنهاية.
