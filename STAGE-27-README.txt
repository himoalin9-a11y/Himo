Himo — Stage 27

Voice messages:
- Android microphone permission.
- In-app voice recording using Android MediaRecorder (AAC/M4A).
- Uploads recordings through the existing 25MB attachment endpoint.
- Voice messages are identified by audio/* content type.
- In-app playback using Android MediaPlayer.
- Stops and cleans up recording/playback when leaving the chat.
- Existing image/file attachments remain supported.

Testing is intentionally deferred until the full build is complete.
